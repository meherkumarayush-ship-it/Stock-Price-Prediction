# 📈 Stock Price Prediction Web App

An end-to-end Machine Learning web application that predicts stock price movements using technical indicators (SMA, RSI, MACD) and a Random Forest Regressor.

## Tech Stack
* **Language:** Python
* **Data Ingestion:** Yahoo Finance API (`yfinance`)
* **ML Model:** Scikit-Learn (`RandomForestRegressor`)
* **Frontend Dashboard:** Streamlit
* **Visualization:** Matplotlib

## How to Run
1. Clone repository: `git clone <your-repo-url>`
2. Activate environment: `.venv\Scripts\activate` (Windows) or `source .venv/bin/activate` (Mac/Linux)
3. Install dependencies: `pip install -r requirements.txt`
4. Run Streamlit app: `streamlit run app.py`
